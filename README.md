# Informe para solicitar folio de seguridad

Aplicación web (móvil) de la Dirección de Seguridad – Grupo Estrella Blanca para capturar el
informe de accidentes e incidencias, compartirlo por WhatsApp y guardarlo en Google Sheets.

- `index.html`: la aplicación completa (React + Tailwind, un solo archivo).
- Los informes se guardan mediante un Google Apps Script vinculado a la hoja de cálculo.

Publicada con GitHub Pages.
